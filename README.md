### 🚀 Featured Projects

#### 📈 [Stockify](https://github.com/Barel-dev/stockify) — Real-time Market Intelligence Platform

A full-stack dashboard for stocks, crypto, and forex. Live WebSocket pricing, AI-driven analysis, and a strategy backtesting engine.

- Real-time data layer over **WebSocket** (Finnhub) and **Server-Sent Events**, eliminating client-side polling
- **Backtesting engine** for RSI, SMA crossover, and MACD strategies, computing Sharpe ratio, max drawdown, and win rate
- AI bull/bear thesis generation via **Claude Haiku**, grounded in live quotes and news
- Tiered **Redis caching** with graceful fallback to stay within API rate limits; 62 tests in CI
- Shipped as an installable PWA

`Next.js 15` · `React 19` · `TypeScript` · `PostgreSQL` · `Redis` · `Tailwind CSS`
